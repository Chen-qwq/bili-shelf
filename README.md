# BiliShelf 哔哩收藏架 v0.5.8

**BiliShelf** 是一个非官方 B 站收藏夹管理浏览器扩展，用侧边栏整理你的收藏夹，支持本地缓存、多条件排序、关键词筛选、悬停浮窗预览、导出备份、插件回收站、倍速/播放模式保留、左视频右收藏架布局、定位当前视频、侧边栏键盘选片和快捷取消收藏。

> 非 B 站官方项目。本项目只使用浏览器中已有的 B 站登录状态访问收藏夹相关页面/接口，不提供下载、破解、绕过权限、绕过风控等功能。

## 功能特点

- **侧边栏收藏夹管理**：在 Edge / Chrome 侧边栏中查看收藏夹和视频列表。
- **本地缓存**：使用 IndexedDB 缓存收藏夹数据，减少频繁请求导致 HTTP 412 的概率。
- **慢速同步与进度条**：分页同步收藏夹视频，显示已同步数量、总数、百分比和当前页；每页保存断点，关闭或中断后可继续。
- **多条件排序**：支持按收藏时间、播放量、时长、发布时间、弹幕数、视频收藏数、标题和 UP 主等字段排序；另有独立的随机排序和随机重排按钮。
- **关键词筛选**：按标题或 UP 主快速过滤收藏视频。
- **悬停浮窗预览**：鼠标悬停封面可预览视频，支持倍速、音量、声音、悬停判定时间和“按住 Alt 才预览”。
- **防卡顿保护**：默认按住 `Alt` 悬停才创建预览播放器，列表分批渲染，封面懒加载；预览会在离开卡片、滚动或切换焦点时销毁 iframe。
- **当前标签页打开**：点击封面、标题或“打开”会替换当前活动标签页，不额外新开窗口。
- **侧边栏键盘选片**：可用 ↑ / ↓ 选择视频，PageUp / PageDown 快速移动，Home / End 到首尾，Enter 打开选中视频。
- **倍速与播放器模式保留**：从侧边栏切换到下一个视频时，可尽量沿用当前播放页的倍速、宽屏和网页全屏状态，并把键盘焦点切回视频页面。
- **左视频右收藏架布局**：可在播放页隐藏推荐、评论等区域，让左侧尽量只保留视频区域，右侧使用浏览器侧边栏管理收藏夹。
- **定位当前视频**：侧边栏新增“转到当前视频”，可定位当前播放页视频在已缓存收藏夹里的位置；同时新增“返回顶端”。
- **快捷取消收藏**：在视频页或侧边栏内按单键快捷键，默认 `U`，即可取消收藏。侧边栏内会取消当前选中视频。
- **回收站防误删**：插件内取消收藏会进入本地回收站，可恢复收藏；界面默认只加载最近 50 条记录，避免历史记录过多时卡顿。
- **导出备份**：支持导出当前收藏夹为 JSON / CSV。

## 安装

### 从源码安装

```bash
git clone https://github.com/Chen-qwq/bili-shelf.git
cd bili-shelf
```

然后打开：

```text
edge://extensions/
```

开启“开发人员模式”，点击“加载解压缩的扩展”，选择本仓库根目录。

Chrome 用户打开：

```text
chrome://extensions/
```

## 浏览器权限

- `storage`：保存设置、收藏夹缓存和插件回收站数据，仅保存在浏览器本地。
- `tabs`：读取当前标签页并在当前标签页打开 B 站视频，支持定位当前视频和保留播放设置。
- `cookies`：读取当前 B 站登录会话中的 `bili_jct`，用于取消或恢复收藏；不会上传 Cookie。
- `sidePanel`：提供浏览器侧边栏界面。
- `scripting`：在 B 站页面环境中发起带登录状态的收藏夹请求，并注入页面事件监听和播放器设置逻辑。
- B 站站点权限：仅授予 `www.bilibili.com`、`space.bilibili.com`、`api.bilibili.com` 和 `player.bilibili.com`，用于收藏夹接口、视频页和播放器预览，不访问开发者服务器。

## 使用建议

- 第一次使用先打开一个 B 站页面并确认已登录。
- 先点“刷新收藏夹列表”，再选择收藏夹并点“慢速同步”；同步过程中可点击“中断同步”，之后再次点击即可从已保存页继续。
- 后续优先使用“打开缓存”，不要频繁同步。
- 收藏夹很大时，保持默认分批显示数量，不建议一次加载全部封面。
- 默认需要按住 `Alt` 再悬停封面才预览；可以在“预览与快捷键”中关闭该选项。
- 遇到 HTTP 412 时，刷新一个 `bilibili.com` 页面，等一会再慢速同步。
- 如果预览导致卡顿，可以关闭悬停预览，或保持“需要按住 Alt 才预览”。
- 如果你想连续在侧边栏里选视频，建议关闭“打开视频后尝试把焦点切回播放页”，并开启“收藏架内启用键盘选择”。
- 如果你经常用方向键控制播放页，可以开启“打开视频后尝试把焦点切回播放页”；受浏览器侧边栏限制，焦点转移不一定每次都成功。
- 想实现“左侧只看视频，右侧只看收藏夹”，可以开启“播放页极简布局”；开启后会自动尝试进入网页全屏。“保留宽屏 / 网页全屏模式”仍用于切换视频时恢复播放模式。
- “转到当前视频”依赖本地缓存；如果当前视频所在收藏夹还没同步，需要先慢速同步对应收藏夹。

## 发布到 GitHub

新建一个 GitHub 空仓库后，在本地执行：

```bash
git init
git add .
git commit -m "init: open source BiliShelf"
git branch -M main
git remote add origin https://github.com/Chen-qwq/bili-shelf.git
git push -u origin main
```

发布版本：

```bash
git tag v0.5.8
git push origin v0.5.8
```

仓库内置 GitHub Actions。推送 `v*.*.*` 标签后，会自动打包扩展 zip 并创建 GitHub Release。
