# BiliShelf 安装和更新

## 开发者模式安装

1. 下载或克隆本仓库。
2. 打开 Edge：

```text
edge://extensions/
```

Chrome 用户打开：

```text
chrome://extensions/
```

3. 开启“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择仓库根目录，也就是包含 `manifest.json` 的目录。
6. 打开一个 B 站页面并登录。
7. 点击扩展图标打开侧边栏。

## 更新

推荐直接在原目录拉取代码：

```bash
git pull
```

然后在扩展管理页点击“重新加载”。

不要频繁移除后重新加载到不同路径，否则浏览器可能分配新的扩展 ID，导致旧 IndexedDB 缓存无法读取。
